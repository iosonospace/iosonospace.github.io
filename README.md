# Sito ufficiale BISCA

Sito statico pronto per GitHub Pages. Non sostituisce il gioco web nel repository bisca-online.

## Pubblicazione
1. Su GitHub, con l'account uomospazio, crea un repository pubblico chiamato esattamente `uomospazio.github.io`. Se esiste già, verifica i contenuti prima di sostituirli.
2. Carica nella radice i contenuti di questa cartella (index.html, styles.css, app-ads.txt, assets e .nojekyll), non la cartella contenitore. .nojekyll è facoltativo per questo sito statico.
3. Settings > Pages: Deploy from a branch, branch main, cartella /(root), Save.
4. Verifica https://uomospazio.github.io/ e https://uomospazio.github.io/app-ads.txt . Il secondo deve mostrare la riga di testo, non una pagina HTML.
5. Imposta https://uomospazio.github.io/ come sito web sviluppatore nella scheda Google Play. Su App Store Connect usa questo sito come URL marketing; il sito offre anche l'assistenza. Mantieni l'URL privacy esistente.
6. In AdMob richiedi una nuova verifica app-ads.txt. La scansione può richiedere tempo dopo l'aggiornamento dello store.
